# Контрольная работа №4 — JavaScript-магазин Urban Set

Интерактивный интернет-магазин на чистом JavaScript, продолжение адаптивного проекта КР №3.

## Реализовано

- 10 товаров из единого массива `js/data.js`; карточки создаются через DOM API без `innerHTML`.
- Поиск по названию, фильтрация по категории, сортировка по цене, рейтингу и названию.
- Страница товара по параметру `?id=`, обработка неверного идентификатора.
- Корзина с изменением количества, удалением, подсчётом через `reduce` и промокодом `STUDENT10`.
- Сохранение корзины, избранного, темы и черновика формы в `localStorage`.
- Валидация имени, e-mail, телефона и согласия с выводом ошибок на странице.
- Светлая/тёмная тема, счётчик корзины, пустые состояния и уведомления.

## JavaScript-файлы

- `data.js` — данные товаров.
- `main.js` — хранилище, корзина, избранное, тема и уведомления.
- `catalog.js` — поиск, фильтры, сортировка и безопасная генерация карточек.
- `product.js` — детальная страница товара.
- `modal.js` — безопасное наполнение окна быстрого просмотра.
- `cart.js` — содержимое корзины, итог и промокод.
- `validation.js` — проверка формы и сохранение черновика.

## Запуск

Откройте `index.html` через Live Server. Для ES-модулей нужен локальный HTTP-сервер.
